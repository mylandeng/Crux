## BUG-001 当前对话框中的历史信息在追问后丢失

- **现象**：用户在 AI 回答页继续追问后，当前对话框里上一轮问答信息会被新一轮内容覆盖或不再可见。
- **期望**：追问应保留当前会话内的历史问答，让用户能连续查看上下文，而不是只看到最新一轮输出。
- **初步判断**：前端目前用单一 `answer-text` / `answer-question` 承载当前回答，流式追问时会重置展示区域；虽然请求侧 `state.messages` 仍用于发送上下文，但 UI 没有维护可渲染的消息列表。
- **建议修复方向**：将回答页从“单条回答详情”改为“当前会话消息流”，每轮 user/assistant 消息追加到列表；引用、事件时间线和后续操作可以绑定到当前选中的 assistant 消息。
- **验收标准**：连续追问 3 轮后，页面仍能看到完整 3 轮用户问题与模型回答；刷新前的同页会话不丢失当前内存状态；追问请求仍带上完整上下文。
